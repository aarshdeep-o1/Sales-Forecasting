# 🪔 Diwali Sales Analysis & Forecasting 📊

This project analyzes Diwali sales data to uncover customer purchasing behavior, product demand, and regional sales trends. Using Python, Pandas, Matplotlib, and machine learning techniques, the project provides valuable business insights and predicts future sales patterns for better decision-making during festive seasons.

## 🚀 Features
- 📈 Sales trend analysis
- 🛍️ Top-selling products identification
- 👥 Customer behavior insights
- 🌍 State-wise and category-wise analysis
- 🔮 Sales forecasting using machine learning
- 📊 Data visualization dashboards

## 🛠️ Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📂 Dataset
The dataset contains Diwali sales records including:
- Customer demographics
- Product categories
- Orders and amount
- State and occupation details

## 📌 Project Goal
To help businesses understand sales patterns and improve marketing, inventory management, and customer targeting strategies during festive seasons.
